# MarketMind AI 🚀
### Autonomous Growth Intelligence Engine for Indian D2C Brands & SMBs
*Built for Google DeepMind & Google Cloud Startup Buildathon India 2026*

---

## 🌟 Overview
India's 63M+ MSMEs and emerging D2C brands (5–50 employees) face severe strategic intelligence gaps, high Customer Acquisition Costs (CAC), and language barriers in traditional AI tools. **MarketMind AI** solves this by providing a voice-enabled, multilingual growth engine backed by persistent business memory and a **Collective Playbook Network**.

---

## 🛠️ Tech Stack ("Boring" & Reliable)
* **Frontend:** React (Modern, clean 5-tab dashboard UI)
* **Backend:** Node.js (Lightweight server-side runtime ensuring secure API key handling)
* **Database & Auth:** Firebase Authentication (Google & Email Login) & Cloud Firestore (Two-tier document storage)
* **AI Core:** Gemini API (`gemini-2.5-flash`) with structured JSON schema enforcement (`responseSchema`)
* **Accessibility:** Native Browser Web Speech API (`SpeechRecognition` & `speechSynthesis`)
* **Cloud Deployment:** Google Cloud Run (Serverless, auto-scaling)

---

## 💡 Core Features
1. **Daily Growth Pulse (Home):** Autonomous morning briefings tailored to the founder's Business DNA, featuring a feed of real-world peer wins from anonymized community playbooks.
2. **Business DNA (Private Memory):** Securely stores company profiles, profit margins, monthly ad budgets, and target competitors under each user's private ID.
3. **Market Radar (Blind-Spot Scanner):** Generates structured strategy cards (Competitor Weakness, Offer Angle, Low-CAC Channel) tagged with confidence badges (*Verified Peer Pattern* vs. *AI Hypothesis*).
4. **What-If Simulator:** Real-time financial sandbox sliders that calculate projected revenue and net profit changes in Indian Rupees (₹).
5. **Outcome Ledger & Playbook Sharer:** Tracks decision statuses and lets founders anonymously share verified successes to help peer businesses.
6. **Bharat Voice-First Accessibility:** Full support for speaking and listening in **Hindi, Telugu, Tamil, Marathi, and Indian English**.
